# Glossary

Every key term A–Z, linked to its unit. Generated from the units' Key terms lists; do not edit by hand.

## #

3-2-1 backup rule
:   Keep 3 copies of data, on 2 different media, with 1 copy offsite. — *[Unit 9](unit-9-malware.md#key-terms)*

## A

Acceptable use
:   ISP component stating what staff may and may not do with the organisation's IT (named but not defined in the courseware). — *[Unit 6](unit-6-security-policy.md#key-terms)*

Access control
:   A security technique that regulates who can view, use, or access certain resources within an organization; a proactive security measure that ensures only authorized individuals can access restricted areas or systems. — *[Unit 8](unit-8-access-control.md#key-terms)*

Access controls (database)
:   Controls that define which users can access which resources, so that only authorized users can access data relevant to their role (least privilege). — *[Unit 11](unit-11-database-security.md#key-terms)*

Access management
:   The component of an access control system that simplifies onboarding and offboarding while ensuring active accounts are secure and up to date. — *[Unit 8](unit-8-access-control.md#key-terms)*

Accountability
:   The security goal that requires actions of an entity to be traced uniquely to that entity; supports nonrepudiation, deterrence, fault isolation, intrusion detection and prevention, and after-action recovery and legal action. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Active attack
:   An attempt to alter system resources or affect their operation. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Active attack (Chapter 2)
:   An attack that alters system resources or their operation by deleting, adding or altering the transmission; threatens data integrity and authentication as well as confidentiality. — *[Unit 2](unit-2-attacks.md#key-terms)*

Admissibility
:   Whether evidence will be accepted in legal proceedings; improper collection or alteration can affect it, depending on the jurisdiction. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Advanced Persistent Threat (APT)
:   A network attack in which an unauthorized person gains access and stays undetected for a long time, intending to steal data rather than cause damage; targets high-value sectors. — *[Unit 2](unit-2-attacks.md#key-terms)*

Adversary (threat agent)
:   Individual, group, organization, or government that conducts or has the intent to conduct detrimental activities. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Adware
:   Software that displays unwanted advertisements (pop-ups, browser redirects); classed as malware when it becomes disruptive and collects information without authorization. — *[Unit 9](unit-9-malware.md#key-terms)*

AES (Advanced Encryption Standard)
:   The gold-standard symmetric block cipher today (AES-128, AES-192, AES-256), used for sensitive government data. — *[Unit 4](unit-4-cryptography.md#key-terms)*

AES encryption
:   The encryption technique used by WPA2 (as AES-CCMP) and WPA3 (as AES-CCMP or AES-GCMP). — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Agent
:   An IDPS component that monitors and analyzes activity on only a single host. — *[Unit 12](unit-12-idps.md#key-terms)*

AI-driven monitoring
:   Using machine learning to enhance database activity monitoring by detecting abnormal behaviours faster than traditional monitoring tools. — *[Unit 11](unit-11-database-security.md#key-terms)*

Alert settings
:   The ability to customize each alert type: toggling it on or off, setting its default priority or severity, and suppressing alerts so the IDPS is not overwhelmed. — *[Unit 12](unit-12-idps.md#key-terms)*

Anomaly-based detection
:   The process of comparing definitions of what activity is considered normal against observed events to identify significant deviations; very effective at detecting previously unknown attacks. — *[Unit 12](unit-12-idps.md#key-terms)*

Anomaly detection
:   Identifying unusual behavior by comparing activity with what is normal. — *[Unit 3](unit-3-os-security.md#key-terms)*

Anonymization
:   Named but not explained in the courseware; permanently removing or transforming identifying details so records can no longer be linked to a person. — *[Unit 11](unit-11-database-security.md#key-terms)*

Antivirus software
:   Primarily an endpoint solution installed on an individual device; scans the local environment for signs of malware, ransomware and other infectious attacks. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Application-level gateway (proxy firewall)
:   A third-generation firewall acting as an intermediary between internal and external systems at OSI Layer 7 (the application layer); offers packet filtering, application-level inspection and URL filtering. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Asymmetric encryption
:   Public-key cryptography: encryption using a pair of keys, a public key shared with anyone and a private key kept secret by the owner; the sender encrypts with the recipient's public key and the recipient decrypts with their private key. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Attack
:   Any kind of malicious activity that attempts to collect, disrupt, deny, degrade, or destroy information system resources or the information itself; a threat that is carried out (threat action). — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Attack surface
:   The reachable and exploitable vulnerabilities in a system (e.g. open ports, services inside a firewall, code processing incoming data, interfaces/SQL/web forms, employees open to social engineering). — *[Unit 2](unit-2-attacks.md#key-terms)*

Attack surface
:   All the points where an attacker could try to enter; firewalls reduce it by blocking unneeded traffic. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Attack surface analysis
:   A technique for assessing the scale and severity of threats to a system; shows where security mechanisms are required, helps make the surface smaller, and sets priorities for testing, strengthening, or modifying the service. — *[Unit 2](unit-2-attacks.md#key-terms)*

Attribute-based access control (ABAC)
:   A complex access control strategy that assigns or denies access to users based on a set of attributes assigned by the owner or administrator; more complicated than RBAC but flexible according to context and evolving levels of risk. — *[Unit 8](unit-8-access-control.md#key-terms)*

Audit trail
:   A record that tracks user activity, helping organizations detect unauthorized access and identify security vulnerabilities (the audit and monitoring component). — *[Unit 8](unit-8-access-control.md#key-terms)*

Authentication
:   The component of an access control system that verifies identity using methods such as passwords, biometric scans, or multi-factor authentication. — *[Unit 8](unit-8-access-control.md#key-terms)*

Authenticity
:   The property of being genuine and able to be verified and trusted; confidence in the validity of a transmission, a message, or message originator. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Authorization
:   The component of an access control system that determines what level of access a user should have to specific data or areas, in alignment with access policies. — *[Unit 8](unit-8-access-control.md#key-terms)*

Automated compliance
:   Automated frameworks that validate database security policies continuously, reducing human error and compliance drift. — *[Unit 11](unit-11-database-security.md#key-terms)*

Automated patch management
:   Applying updates to database software automatically, reducing exposure to newly discovered vulnerabilities. — *[Unit 11](unit-11-database-security.md#key-terms)*

Availability
:   Assures that systems work promptly and service is not denied to authorized users. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Avalanche effect
:   The property that a tiny change in the input, even one bit, causes a significant and unpredictable change in the hash output. — *[Unit 4](unit-4-cryptography.md#key-terms)*

## B

Backdoor
:   An unauthorized entry point into a system, enabling data exfiltration, installation of other malware, and persistent access. — *[Unit 9](unit-9-malware.md#key-terms)*

Backup and disaster recovery
:   Plans and separately stored, frequently tested backup copies that protect against data loss caused by ransomware, outages, or corruption. — *[Unit 11](unit-11-database-security.md#key-terms)*

Behavioral analysis
:   Studying patterns in file and process activity to flag anomalies; identifies threats that bypass signature-based detection, including polymorphic and memory-based malware. — *[Unit 9](unit-9-malware.md#key-terms)*

Blacklist
:   A list of discrete entities (hosts, ports, ICMP types and codes, applications, usernames, URLs, filenames, file extensions) previously determined to be associated with malicious activity. — *[Unit 12](unit-12-idps.md#key-terms)*

BLAKE2 and BLAKE3
:   High-speed, secure alternatives to SHA-2 and SHA-3; BLAKE3 supports parallel processing and incremental updates. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Block cipher
:   A symmetric cipher that processes fixed-size data blocks (e.g. AES, DES, Blowfish). — *[Unit 4](unit-4-cryptography.md#key-terms)*

Bot-herder
:   The single attacker who controls a botnet. — *[Unit 9](unit-9-malware.md#key-terms)*

Botnet
:   The large numbers of compromised systems used together in a distributed denial-of-service attack. — *[Unit 2](unit-2-attacks.md#key-terms)*

Botnet
:   A network of infected computers controlled by a single attacker (the bot-herder), used for mass spam, DDoS attacks and financial theft. — *[Unit 9](unit-9-malware.md#key-terms)*

Bring-your-own-device (BYOD)
:   Policies that let employees use their own devices on the organisation's network; with IoT, the main driver of endpoint growth that makes NAC necessary. — *[Unit 8](unit-8-access-control.md#key-terms)*

Brute force attack
:   Repeated attempts to guess passwords or encryption keys. — *[Unit 3](unit-3-os-security.md#key-terms)*

Buffer overflow
:   A programming flaw where excess data overwrites adjacent memory, allowing malicious code execution. — *[Unit 3](unit-3-os-security.md#key-terms)*

## C

CCMP (Counter Mode Cipher Block Chaining Message Authentication Code Protocol)
:   The authenticated encryption protocol designed for wireless LAN products that implement the IEEE 802.11i amendment to the IEEE 802.11 standard; also called Counter CBC-MAC Protocol. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Center for Internet Security (CIS)
:   A body that publishes security benchmarks (configuration checklists) followed in secure configuration. — *[Unit 3](unit-3-os-security.md#key-terms)*

Centralized identity management
:   The best practice of unifying access control systems to avoid separate identity silos and improve efficiency. — *[Unit 8](unit-8-access-control.md#key-terms)*

Certificate authority (CA)
:   A publicly trusted body that validates a requester's information, manages domain control verification, verifies key ownership and signs digital certificates. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Certificate signing request (CSR)
:   The request through which an individual, organization or website submits the information to be validated and its public key to a CA. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Chain of custody
:   A record of everyone who handled a piece of evidence, when and why, used to show it was not tampered with (site definition). — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Change management
:   ISP component that controls additions and changes to software and hardware (named but not defined in the courseware). — *[Unit 6](unit-6-security-policy.md#key-terms)*

Checksum
:   A hash of a data file used for a data integrity check; detects modification but does not stop an attacker replacing both file and hash. — *[Unit 4](unit-4-cryptography.md#key-terms)*

CIA triad
:   Confidentiality, integrity and availability: the three fundamental security objectives for both data and for information and computing services. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Cipher suite
:   A set of algorithms agreed in the handshake, defining which are used for key exchange, encryption and message authentication. — *[Unit 4](unit-4-cryptography.md#key-terms)*

CISO
:   Chief Information Security Officer: the senior manager responsible for information security; named in the courseware as an example under roles and responsibilities. — *[Unit 6](unit-6-security-policy.md#key-terms)*

Clearance and label (MAC)
:   In MAC, subjects are assigned clearances and objects are assigned labels, such as "confidential", "secret" and "top secret". — *[Unit 8](unit-8-access-control.md#key-terms)*

Client certificate
:   A digital ID identifying an individual user to another user or machine, or one machine to another (e.g. signed email, access to protected databases). — *[Unit 4](unit-4-cryptography.md#key-terms)*

Cloud-native firewall
:   A firewall specifically created to operate in a particular cloud environment, tightly integrated with providers such as AWS, Azure and Google Cloud. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Code signing certificate
:   A certificate used by a developer or publisher to sign software, confirming it is genuine and has not been tampered with. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Code viewing and editing
:   The ability to see and edit detection-related code (usually signatures), to validate alerts, identify false positives and fully customize detection. — *[Unit 12](unit-12-idps.md#key-terms)*

Collision resistance
:   The hash function minimizes the chance that two distinct inputs produce identical hash values. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Complete mediation
:   Every access must be checked against the access control mechanism, without relying on cached decisions. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Compliance drift
:   The gradual slide of systems away from required security settings as small changes accumulate. — *[Unit 11](unit-11-database-security.md#key-terms)*

Computer security
:   Measures and controls that ensure confidentiality, integrity, and availability of information system assets including hardware, software, firmware, and information being processed, stored, and communicated. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Confidentiality (ethical issue)
:   Protecting information from unauthorized disclosure. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Conflict of interest
:   A situation where a professional's personal interest competes with their duty (site definition; the courseware lists avoiding it as a responsibility). — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Console
:   A program that provides an interface for the IDPS's users and administrators, used for administration, for monitoring and analysis, or for both. — *[Unit 12](unit-12-idps.md#key-terms)*

Continuous data discovery
:   Continually locating and classifying sensitive data wherever it resides, from cloud data stores to legacy database systems. — *[Unit 11](unit-11-database-security.md#key-terms)*

Control framework
:   The set of security controls built on the direction given by an ISP to secure the organization against external and internal threats. — *[Unit 6](unit-6-security-policy.md#key-terms)*

Correlation
:   Matching event information from multiple sensors or agents, such as finding events triggered by the same IP address. — *[Unit 12](unit-12-idps.md#key-terms)*

Countermeasure
:   A device or technique whose objective is to impair adversarial activity, or prevent espionage, sabotage, theft, or unauthorized access to or use of sensitive information or information systems. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Cracker
:   Someone able to defeat anti-piracy protections of computer programs who uses their knowledge in an unethical way. — *[Unit 2](unit-2-attacks.md#key-terms)*

Cryptographic hash function
:   A mathematical algorithm that transforms input data of any length into a fixed-length hash value; intended to be fast, deterministic and one-way. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Cryptography
:   The science of securing communication and data by converting it into a form that can only be understood by the intended recipient; ensures confidentiality, integrity and authenticity. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Cryptojacking
:   Malware that hijacks a system's computing resources to mine cryptocurrency without the user's knowledge or consent, degrading performance and shortening hardware lifespan. — *[Unit 9](unit-9-malware.md#key-terms)*

Customer-managed keys
:   Encryption keys created and controlled by the cloud customer rather than the provider, used to encrypt cloud data. — *[Unit 11](unit-11-database-security.md#key-terms)*

Cybercrime
:   Criminal activities involving computers, networks, or digital systems, e.g. unauthorized access, computer-related fraud, identity theft, malware distribution, cyberstalking, data theft and denial-of-service attacks. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Cyberstalking
:   Using electronic communication to harass, threaten or persistently follow a person; an example of cybercrime (site definition). — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

## D

Data at rest
:   Stored data, such as files on computers and storage devices (e.g. USB flash drives); encrypting it protects it should physical security measures fail. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Database activity monitoring
:   Real-time monitoring that gives visibility into anomalies and detects unusual logins, abnormal database connections, and privilege escalations. — *[Unit 11](unit-11-database-security.md#key-terms)*

Database firewall
:   A firewall that blocks malicious database traffic and enforces firewall rules; it can detect and prevent SQL injection and other suspicious activity before they reach the core database server. — *[Unit 11](unit-11-database-security.md#key-terms)*

Database security
:   The collection of tools, controls, and processes designed to protect databases from unauthorized access, misuse, and corruption; it keeps sensitive data safe from external hackers, malicious insiders, and human error. — *[Unit 11](unit-11-database-security.md#key-terms)*

Database server (IDPS)
:   A repository for event information recorded by sensors, agents, and management servers. — *[Unit 12](unit-12-idps.md#key-terms)*

Data classification
:   ISP component that defines which information is confidential, restricted, general, etc., with handling rules for each class. — *[Unit 6](unit-6-security-policy.md#key-terms)*

Data confidentiality
:   Assures that private or confidential information is not made available or disclosed to unauthorized individuals. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Data exfiltration
:   Data being carried out of the organisation without authorisation; firewalls help mitigate it by restricting certain outgoing traffic. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Data integrity
:   Assures that information and programs are changed only in a specified and authorized manner. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Data in transit
:   Data being transferred via networks, mobile telephones, wireless devices, Bluetooth or ATMs; encrypted because it is difficult to physically secure all access to networks. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Data loss prevention (DLP)
:   A cybersecurity solution that blocks intentional and accidental data disclosures. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Data masking
:   Hiding identifiable information during testing or analytics, so developers work with just the data they need. — *[Unit 11](unit-11-database-security.md#key-terms)*

Data packet
:   A unit of data crossing a network; a firewall inspects each packet and decides whether to allow or block it. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Data-protection laws
:   Laws that regulate how organizations collect, process, store, and share personal information. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Data subject
:   The individual the personal data is about; data-protection laws may require organizations to respond to their requests (site definition). — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Deep packet inspection (DPI)
:   A method of examining the contents of data packets as they pass through network checkpoints, analysing a larger range of information to find otherwise hidden threats. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Default passwords
:   Default or weak passwords, which make systems easy targets. — *[Unit 3](unit-3-os-security.md#key-terms)*

Defense in depth (database)
:   Combining network security, access management, and encryption, with each layer (web server, application, database server) enforcing unique security controls. — *[Unit 11](unit-11-database-security.md#key-terms)*

Defined objectives
:   What a security test is intended to determine. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Defined scope
:   The systems and activities covered by a security test. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Denial of Service (DoS)
:   An incident in which a user or organization is deprived of the services of a resource they would normally expect to have. — *[Unit 2](unit-2-attacks.md#key-terms)*

Denial of Service (DoS)
:   Overwhelming a system to make it unavailable to legitimate users. — *[Unit 3](unit-3-os-security.md#key-terms)*

DES (Data Encryption Standard)
:   An older symmetric algorithm, now largely obsolete due to vulnerabilities; improved on by Triple DES (3DES), which is also being phased out. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Diffie-Hellman (DH)
:   An asymmetric protocol used strictly for safely exchanging a secret key over an open network, not for encrypting files; variant ECDH. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Digital certificate
:   A file or electronic password that proves the authenticity of a device, server or user through cryptography and PKI; contains identifying information and a copy of the holder's public key, signed by a CA. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Digital evidence
:   Information in digital form used in an investigation, e.g. emails, log files, hard-drive data, mobile-device data, network records, cloud records. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Digital forensics
:   The identification, collection, preservation, examination, and analysis of digital evidence. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Digital rights management (DRM)
:   Systems that prevent unauthorized use or reproduction of copyrighted material and protect software against reverse engineering; an example of encryption of data at rest. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Digital signature
:   An electronic signature that authenticates the identity of the sender or signer and possibly ensures message integrity; in the hash-based scheme, the document's hash encrypted with the sender's private key. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Disaster recovery plan
:   A plan for fighting a network attack or a physical emergency (fire, flood, earthquake); without one, the response is left to the judgment of the staff on hand. — *[Unit 6](unit-6-security-policy.md#key-terms)*

Discretionary access control (DAC)
:   An access control model in which the data owner decides to grant access rights based on rules that they specify; the least restrictive, and least recommended, type for commercial and business security. — *[Unit 8](unit-8-access-control.md#key-terms)*

Distributed database
:   A database whose data is spread across multiple regions for performance and availability; needs encryption on all connections and global data protection measures. — *[Unit 11](unit-11-database-security.md#key-terms)*

Distributed Denial of Service (DDoS)
:   A denial-of-service attack in which large numbers of compromised systems (a botnet) attack a single target. — *[Unit 2](unit-2-attacks.md#key-terms)*

DNS filtering
:   Blocking access to known malicious domains and command-and-control servers, so malware cannot communicate with attackers. — *[Unit 9](unit-9-malware.md#key-terms)*

DNS security
:   An NGFW capability to monitor, detect and prevent DNS layer attacks. — *[Unit 5](unit-5-firewalls.md#key-terms)*

DSA (Digital Signature Algorithm)
:   A standard used only to verify the authenticity and identity of a digital message or sender, not for hiding data; variant ECDSA. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Dwell time
:   How long a threat remains inside a system before it is contained; reduced by automated containment and response. — *[Unit 9](unit-9-malware.md#key-terms)*

Dynamic blacklist
:   A blacklist generated by the IDPS to temporarily block recently detected threats, e.g. activity from an attacker's IP address. — *[Unit 12](unit-12-idps.md#key-terms)*

Dynamic profile
:   A profile that is adjusted constantly as additional events are observed. — *[Unit 12](unit-12-idps.md#key-terms)*

## E

ECC (Elliptic Curve Cryptography)
:   An asymmetric approach using algebraic curves that gives high security with much smaller keys than RSA; ideal for mobile and internet-connected devices. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Economy of mechanism
:   Security measures in hardware and software should be as simple and small as possible. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Electronic fraud
:   Fraud committed using computers and networks, e.g. online banking fraud, identity-related fraud, fake online transactions, phishing scams, manipulation of electronic records. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Email security gateway
:   A filter that removes phishing attempts, malicious attachments and spoofed senders before messages reach the inbox. — *[Unit 9](unit-9-malware.md#key-terms)*

Employee on/off boarding
:   ISP component covering security steps when staff join (accounts, training) and leave (removing access) (named but not defined in the courseware). — *[Unit 6](unit-6-security-policy.md#key-terms)*

Encapsulation
:   A specific form of isolation based on object-oriented functionality: data reachable only through the protected subsystem's procedures at designated entry points. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Encryption at rest and in transit
:   Encrypting sensitive data while stored and while moving over a network, to protect it from unauthorized access. — *[Unit 3](unit-3-os-security.md#key-terms)*

Endpoint detection and response (EDR)
:   Continuously monitors endpoint activity and analyzes behavior patterns in real time; detects advanced threats and supports faster investigation and remediation. — *[Unit 9](unit-9-malware.md#key-terms)*

Essential security practices
:   The 17 practices listed in Chapter 1, from access control to system and information integrity, that an organisation should carry out to protect its information systems. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Ethical hacking
:   Authorized security testing performed to identify vulnerabilities and improve security. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Ethical principles for security professionals
:   Respect privacy; obtain authorization before testing; maintain confidentiality; protect information entrusted to them; avoid unnecessary harm; be honest and transparent; respect intellectual property; follow applicable laws and professional standards; report vulnerabilities responsibly. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Ethics
:   What is considered right or wrong conduct. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Extended detection and response (XDR)
:   Extends detection and response beyond endpoints to networks and cloud workloads, giving broader visibility across multi-cloud and hybrid environments. — *[Unit 9](unit-9-malware.md#key-terms)*

Extended validation (EV) certificate
:   The TLS/SSL certificate form offering full business authentication and the highest level of trust; used by large organizations and the financial industry. — *[Unit 4](unit-4-cryptography.md#key-terms)*

## F

Fail-safe defaults
:   Access decisions should be based on permission rather than exclusion; the default is lack of access. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

False positive
:   Benign activity that an IDPS wrongly identifies as malicious (used but not defined in the courseware). — *[Unit 12](unit-12-idps.md#key-terms)*

Fileless malware
:   Malware that operates entirely in memory without writing files to disk, working through legitimate tools such as PowerShell or WMI; hard to detect with traditional measures. — *[Unit 9](unit-9-malware.md#key-terms)*

Firewall
:   A network security device designed to monitor, filter, and control incoming and outgoing network traffic based on predetermined security rules; its primary purpose is to establish a barrier between a trusted internal network and untrusted external networks. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Firewall-as-a-service (FWaaS)
:   A deployment model where vendors deliver the firewall solution as a cloud-based service; easy to scale and configure. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Freeware
:   Software free of charge to use, usually without access to the source code (site definition). — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

## G

GCMP (Galois Counter Mode Protocol)
:   A robust encryption and authentication protocol giving enhanced security and efficiency in wireless communication; an improvement over CCMP, used in WPA3. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

## H

Hacker
:   A person with good or excellent IT skills whose know-how is useful in finding vulnerabilities and security holes; the courseware calls the activity helpful and useful. — *[Unit 2](unit-2-attacks.md#key-terms)*

Hardening
:   Securing the operating system by disabling unnecessary features and services. — *[Unit 3](unit-3-os-security.md#key-terms)*

Host attacks
:   Attacks on vulnerabilities in certain computer operating systems or in how the system is set up and administered. — *[Unit 2](unit-2-attacks.md#key-terms)*

Host-based IDPS
:   Monitors the characteristics of a single host and the events occurring within it; most commonly deployed on critical hosts such as publicly accessible servers and servers containing sensitive information. — *[Unit 12](unit-12-idps.md#key-terms)*

Hosted firewall
:   A firewall installed directly on an endpoint (an individual device) for extra protection. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Human attack surface
:   Vulnerabilities created by personnel or outsiders, such as social engineering, human error, and trusted insiders. — *[Unit 2](unit-2-attacks.md#key-terms)*

Hybrid cryptosystem
:   A system that combines categories of cryptography, such as SSL: asymmetric for key exchange and authentication, symmetric for bulk data, hashes for integrity. — *[Unit 4](unit-4-cryptography.md#key-terms)*

:   Multiple privilege attributes are required to access a restricted resource; also, dividing a program into parts limited to the privileges each needs. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Server hardening
:   Securing a server by removing unneeded services, software and accounts and applying secure settings; the courseware's example of server security. — *[Unit 6](unit-6-security-policy.md#key-terms)*

Session key
:   A shared secret (symmetric) key established during a TLS/SSL handshake and used to encrypt and authenticate the session's data. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Session key
:   The key used to encrypt a wireless session; 64/128 bit in WEP, 128 bit in WPA and WPA2, 128/256 bit in WPA3 (per the courseware's table). — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

SHA-1
:   Secure Hash Algorithm 1: improved on MD5 but deprecated after practical collision attacks, including for SSL/TLS certificates and digital signatures. — *[Unit 4](unit-4-cryptography.md#key-terms)*

SHA-2
:   The industry-standard hash family (SHA-256, SHA-512) with 256- and 512-bit outputs; used in secure protocols, blockchain and password hashing. — *[Unit 4](unit-4-cryptography.md#key-terms)*

SHA-3 (Keccak)
:   The latest NIST hash standard, using a sponge construction different from SHA-2; suited to long-term security. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Shadow AI
:   AI tools and applications used by employees without the organisation's approval or knowledge; a new entry point for data exposure. — *[Unit 9](unit-9-malware.md#key-terms)*

Shared responsibility model
:   In cloud deployments, providers secure the physical infrastructure, while customers safeguard data, database user accounts, and access controls. — *[Unit 11](unit-11-database-security.md#key-terms)*

Signature
:   A pattern that corresponds to a known attack or type of attack. — *[Unit 12](unit-12-idps.md#key-terms)*

Signature-based detection
:   The process of comparing signatures against observed events to identify possible attacks; the simplest method, very effective against known attacks but largely ineffective against unknown attacks, evasion and variants. — *[Unit 12](unit-12-idps.md#key-terms)*

Social engineering
:   Trying to gain access through social means, such as pretending to be a legitimate system user or administrator, or tricking people into revealing secrets. — *[Unit 2](unit-2-attacks.md#key-terms)*

Software attack surface
:   Vulnerabilities in application, utility, or operating system code; a particular focus is Web server software. — *[Unit 2](unit-2-attacks.md#key-terms)*

Software-defined wide-area network (SD-WAN)
:   An architecture delivering dynamic path selection based on business or application policy, centralized policy and management of appliances, VPN, and zero-touch configuration. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Software licence
:   The permission, with conditions, under which software may be used or distributed; installing or distributing software in violation of its license can create legal problems. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Software piracy
:   Copying, installing or distributing software without the permission of its owner; an example of an intellectual-property issue. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Spyware
:   Malware designed to secretly monitor user activity and collect personal information, transmitting it to attackers (e.g. for identity theft). — *[Unit 9](unit-9-malware.md#key-terms)*

SQL injection
:   An attack that exploits flaws in poorly sanitized database queries: input typed by the attacker is run by the database as SQL. Relational databases are most prone to it. — *[Unit 11](unit-11-database-security.md#key-terms)*

SSH (Secure Shell)
:   A cryptographic network protocol for secure data communication, command-line login, remote command execution and other secure network services between two networked computers. — *[Unit 4](unit-4-cryptography.md#key-terms)*

SSL (Secure Sockets Layer)
:   The predecessor of TLS, developed by Netscape in the 1990s; largely superseded by TLS due to security vulnerabilities. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Stale credentials
:   Accounts and passwords that are no longer needed (e.g. of staff who have left); removed by regular reviews of user accounts. — *[Unit 11](unit-11-database-security.md#key-terms)*

Stateful firewall
:   A second-generation firewall that tracks the most recent or immediate status of active connections and uses state and context to identify threats. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Stateful (in stateful protocol analysis)
:   The IDPS is capable of understanding and tracking the state of network, transport, and application protocols that have a notion of state, including pairing requests with responses. — *[Unit 12](unit-12-idps.md#key-terms)*

Stateful protocol analysis
:   The process of comparing predetermined profiles of generally accepted definitions of benign protocol activity for each protocol state against observed events to identify deviations, using vendor-developed universal profiles. — *[Unit 12](unit-12-idps.md#key-terms)*

Stateless firewall
:   A first-generation firewall that inspects traffic packet by packet using only the packet header, without storing information about the state of the connection; fast and inexpensive. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Static profile
:   A profile that, once generated, is unchanged unless the IDPS is specifically directed to generate a new profile. — *[Unit 12](unit-12-idps.md#key-terms)*

Stream cipher
:   A symmetric cipher that encrypts data one bit at a time (e.g. RC4). — *[Unit 4](unit-4-cryptography.md#key-terms)*

Symmetric encryption
:   A method of scrambling data using a single shared secret key that both encrypts and decrypts; also called secret key cryptography, private key cryptography or symmetric key encryption. — *[Unit 4](unit-4-cryptography.md#key-terms)*

System integrity
:   Assures that a system performs its intended function in an unimpaired manner, free from deliberate or inadvertent unauthorized manipulation. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

System resource (asset)
:   A major application, general support system, high impact program, physical plant, mission critical system, personnel, equipment, or a logically related group of systems. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

## T

Tabletop exercise
:   A discussion-based rehearsal in which the response team talks through a simulated incident to test and refine the incident response plan. — *[Unit 9](unit-9-malware.md#key-terms)*

Technology/logical access control
:   The key aspect of access control that manages connections to digital systems, including data access, applications, and networks, through user authentication systems, role-based permissions, and cybersecurity measures. — *[Unit 8](unit-8-access-control.md#key-terms)*

Threat
:   Any circumstance or event with the potential to adversely impact operations, assets, individuals, other organizations, or the Nation through an information system via unauthorized access, destruction, disclosure, modification of information, and/or denial of service. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Threat consequence
:   The undesirable violation of security that results from a successful attack (threat action). — *[Unit 1](unit-1-security-concepts.md#key-terms)*

Threat intelligence integration
:   Using threat intelligence feeds that give context on emerging attack patterns and indicators of compromise, to anticipate threats and respond more effectively. — *[Unit 9](unit-9-malware.md#key-terms)*

Threshold
:   A value that sets the limit between normal and abnormal behavior, usually a maximum acceptable level (e.g. 5 failed connection attempts in 60 seconds). — *[Unit 12](unit-12-idps.md#key-terms)*

TKIP (temporal key integrity protocol)
:   The encryption used by WPA to improve key management and integrity checks over WEP. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

TLS handshake protocol
:   The part of TLS that authenticates the server (sometimes the client) by digital certificate, agrees a cipher suite and exchanges keys to establish shared session keys. — *[Unit 4](unit-4-cryptography.md#key-terms)*

TLS record protocol
:   The part of TLS that secures data during the connection, using the negotiated cipher suite and symmetric keys to encrypt data and create MACs. — *[Unit 4](unit-4-cryptography.md#key-terms)*

TLS/SSL
:   Secure protocols for communication (Transport Layer Security / Secure Sockets Layer); SSL is obsolete and TLS is used today. — *[Unit 3](unit-3-os-security.md#key-terms)*

TLS/SSL certificate
:   A certificate on a server that authenticates it and enables private, encrypted communication, signified by HTTPS; comes as domain validated, organization validated or extended validation. — *[Unit 4](unit-4-cryptography.md#key-terms)*

TLS (Transport Layer Security)
:   A cryptographic protocol providing secure, encrypted communication over a network with identity verification; made of the handshake and record protocols; secures HTTPS, SMTP and FTPS. — *[Unit 4](unit-4-cryptography.md#key-terms)*

Training period
:   The period of time over which an IDPS generates an initial profile of normal behavior. — *[Unit 12](unit-12-idps.md#key-terms)*

Trojan horse
:   Malware that disguises itself as legitimate software to trick users into installing it, delivering payloads such as backdoor access or data theft. — *[Unit 9](unit-9-malware.md#key-terms)*

## U

UEBA (user and entity behavior analytics)
:   Establishes a baseline of normal activity for users and entities, then flags deviations, catching threats even when no malware signature exists. — *[Unit 9](unit-9-malware.md#key-terms)*

Unauthorized access
:   Accessing a computer system without permission; both an ethical and potentially legal problem, prohibited by law in many jurisdictions. — *[Unit 10](unit-10-ethics-legal.md#key-terms)*

Unmonitored database activity
:   Logins and queries on production databases that nobody watches, so small oversights and attacks go unnoticed. — *[Unit 11](unit-11-database-security.md#key-terms)*

Unpatched software
:   Failure to apply security patches, which exposes systems to known exploits. — *[Unit 3](unit-3-os-security.md#key-terms)*

URL filtering
:   Allowing or blocking traffic according to the web address requested; offered by proxy firewalls. — *[Unit 5](unit-5-firewalls.md#key-terms)*

## V

Virtual firewall
:   A software-based firewall running on virtualized infrastructure such as hypervisors or cloud platforms; flexible and can be moved between clouds. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Virtualization
:   Running critical applications in isolated virtual environments to reduce the risk of compromise. — *[Unit 3](unit-3-os-security.md#key-terms)*

Virtual Private Network (VPN)
:   Described by the courseware as a type of proxy server; extends the private network across a public one by establishing an encrypted tunnel between remote devices and the corporate network. — *[Unit 5](unit-5-firewalls.md#key-terms)*

Virus
:   Malware that replicates by attaching to files and spreads when users transfer infected files; can corrupt files or disrupt systems. — *[Unit 9](unit-9-malware.md#key-terms)*

Vulnerability
:   Weakness in an information system, system security procedures, internal controls, or implementation that could be exploited or triggered by a threat source. — *[Unit 1](unit-1-security-concepts.md#key-terms)*

## W

War dialing
:   Using computer software and a modem to search for desktop computers equipped with modems that answer, providing a potential path into a corporate network. — *[Unit 2](unit-2-attacks.md#key-terms)*

WEP (Wired Equivalent Privacy)
:   Wireless security protocol developed in 1997 using RC4 encryption and shared key authentication; its flaws were widely exploited, making it obsolete. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Whitelist
:   A list of discrete entities known to be benign, typically used protocol-by-protocol to reduce or ignore false positives. — *[Unit 12](unit-12-idps.md#key-terms)*

Wi-Fi Easy Connect
:   A WPA3 feature that simplifies device configuration. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Wi-Fi Enhanced Open
:   The WPA3 type for non-password-protected networks. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Wireless IDPS
:   Monitors wireless network traffic and analyzes wireless networking protocols; cannot see suspicious activity in application or higher-layer protocols carried over the wireless traffic. — *[Unit 12](unit-12-idps.md#key-terms)*

Wireless network security protocols
:   WEP, WPA, WPA2 and WPA3: the four types of protocol that secure wireless networks, each with increasing levels of security. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Wireless security
:   Creates layers of defense by combining encryption, authentication, access control, device security and intrusion detection to defend against illegal access and ensure network security. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Worm
:   Malware closely related to a virus that can replicate on its own from machine to machine, without the help of a user. — *[Unit 9](unit-9-malware.md#key-terms)*

WPA2 (Wi-Fi Protected Access II)
:   Wireless security standard released in 2004 that uses AES encryption (AES-CCMP); the industry standard, but vulnerable to KRACK. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

WPA3-Enterprise
:   The WPA3 type for organizational settings. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

WPA3-Personal
:   The WPA3 type for home use. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

WPA3 (Wi-Fi Protected Access III)
:   Wireless security standard launched in 2018 with enhanced encryption (CCMP or GCMP), improved protection against dictionary brute force attacks and Wi-Fi Easy Connect; adoption is slow. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

WPA-Enterprise
:   The WPA mode for enterprises that use RADIUS servers. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

WPA-Personal
:   The WPA mode for home networks. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

WPA (Wi-Fi Protected Access)
:   Successor to WEP launched in 2003; uses TKIP encryption (128-bit) and has two modes, WPA-Personal and WPA-Enterprise. — *[Unit 7](unit-7-wireless-mobile.md#key-terms)*

Zero-trust architecture
:   A model that assumes no implicit trust and verifies every user access and network access request across database servers and web servers. — *[Unit 11](unit-11-database-security.md#key-terms)*
